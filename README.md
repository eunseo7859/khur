# KHUR v2 — 좌석별 QR 등록·변경
Python + Streamlit + Supabase. 학교 공식 서비스가 아닌 경진대회 시제품입니다.

## 이번 버전의 흐름
A01 QR 스캔 → A01 화면 → 로그인 → 이용하기.
A02 QR 스캔 → 같은 계정으로 로그인 → 기존 A01 확인 → 변경하기 → A01 반납 및 A02 등록을 하나의 트랜잭션으로 처리.
전체 좌석을 골라 예약하는 화면은 없습니다. QR의 좌석이 첫 화면입니다.

**로그인 자동 유지가 구현된 버전은 아닙니다.** 새 QR, 새 탭, 새로고침 시 재로그인이 필요할 수 있습니다. 동일 계정으로 로그인하면 데이터베이스의 기존 좌석을 찾아 안전하게 변경할 수 있습니다. 이메일/비밀번호는 URL에 담지 않습니다.

## 1. GitHub 업로드
압축을 풀어 폴더 안의 파일을 저장소 최상위에 올립니다. ZIP 자체를 업로드하지 마세요. 이전 app.py와 requirements.txt는 이번 파일로 교체하세요.

## 2. Supabase 준비 (최초 1회)
1. Supabase에서 새 프로젝트를 생성합니다.
2. SQL Editor에서 `supabase_setup.sql` 전체를 붙여 넣고 실행합니다.
3. 프로젝트의 API 설정에서 Project URL과 **anon 공개 키(legacy anon key)** 를 복사합니다. service_role/secret 키는 사용하지 마세요.
4. Authentication에서 Email 로그인을 활성화합니다.
5. 시연용 계정은 Authentication → Users → Add user/Create user에서 직접 만들고 이메일 확인 완료(자동 확인) 옵션을 사용하면 편리합니다. 메뉴 명칭은 화면에 따라 다를 수 있습니다. 실제 학교 비밀번호를 쓰지 마세요.
6. 앱 내 회원가입을 사용할 경우 이메일 확인 설정에 따라 메일 인증이 필요합니다. 시연은 미리 만든 두 테스트 계정을 추천합니다.

## 3. Streamlit 배포
1. Streamlit Community Cloud에서 저장소 연결, main 파일 `app.py` 선택.
2. 앱의 설정/Advanced settings/Secrets 영역에 아래 TOML을 입력합니다.
```toml
SUPABASE_URL = "https://YOUR_PROJECT.supabase.co"
SUPABASE_ANON_KEY = "YOUR_LEGACY_ANON_PUBLIC_KEY"
```
3. 저장 후 배포/재시작합니다. 이 실제 설정 파일은 GitHub에 업로드하지 마세요.

## 4. 좌석마다 QR 붙이기
앱의 `좌석 QR 출력 도구`를 열고 배포 주소를 입력하세요. 20개 QR을 ZIP으로 다운로드할 수 있습니다.
A01 QR은 앱 주소의 `?seat=A01`, A02 QR은 `?seat=A02`로 연결됩니다.
QR 이미지 파일명에 좌석 번호가 있습니다. 인쇄물에도 좌석 번호를 크게 적고 해당 좌석에 부착하세요.
예시 좌석은 A01~A20이며 실제 공대 좌석 수·배치가 아닙니다. 숫자 1~20으로 표시하려면 코드와 DB를 일관되게 변경해야 합니다.

## 5. 시연 테스트
- 계정 1로 A01 QR 스캔·로그인·등록
- A02 QR 스캔·같은 계정 재로그인·변경 → A01은 비고 A02만 내 좌석
- 별도 브라우저에서 계정 2로 같은 좌석 신청 → 이용 중 표시/등록 실패
- 계정 2가 쓰는 좌석으로 변경 시 계정 1의 기존 좌석 유지
- 반납 후 다른 계정에서 등록
- 서버 재시작 후 같은 계정 로그인 시 좌석 기록 유지

## 구조·안전성
영구 기록은 Supabase PostgreSQL에 저장합니다. 행 수준 보안(RLS)을 켜고 테이블 직접 접근을 차단했습니다. 인증된 RPC만 사용하며 auth.uid()로 이용자를 식별합니다. 계정 ID를 사용자 입력으로 받지 않습니다. 공통 트랜잭션 잠금 및 좌석/사용자 고유 제약조건으로 중복과 변경 충돌을 방지합니다. 로그인 클라이언트는 브라우저 세션별로 분리합니다.
만료 시각이 지난 좌석은 현황에서 제외되며, 다음 등록 때 만료 기록을 정리합니다. 실시간 자동 갱신은 아닙니다.

## 제한
- 영구 자동로그인/학교 SSO/현장 방문 인증/관리자/이용 이력 미구현
- 한 계정당 한 좌석이지 한 학생당 한 좌석을 보장하지는 않음
- QR 공유 시 외부 접속 가능
- 종료 예정 시각은 UTC로 표시
- QR 출력 도구는 공개 접근 가능하지만 예약 변경에는 로그인 필요
- 실제 운영 전 인증 강화, 개인정보 처리, 학교 승인 및 보안 검토 필요

## 로컬 실행
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
로컬 설정은 `.streamlit/secrets.toml`에 작성합니다. `secrets.example.toml`을 참고하세요.

## 검증 범위
Python 문법과 SQLite로 재현한 등록/변경/반납 알고리즘은 검사했습니다. 실제 Supabase SQL 실행, 인증, 클라우드 배포 및 휴대전화 QR 흐름은 제공자 계정을 연결한 후 위 절차로 검증해야 합니다.
