# KHUR — Python 좌석 등록·변경 데모

두리서의 공대 열람실 QR 기반 좌석 서비스 시제품입니다. **학교 공식 서비스가 아니며 실제 운영용이 아닙니다.**

## GitHub에 올리기
1. 새 GitHub 저장소를 만듭니다.
2. 이 ZIP의 압축을 풀고, 폴더 안의 `app.py`, `requirements.txt`, `.gitignore`, `README.md`를 저장소 최상위에 업로드합니다. ZIP 자체만 올리지 마세요.
3. Streamlit Community Cloud에서 저장소를 연결하고 메인 파일로 `app.py`를 지정해 배포합니다.
4. 배포 주소를 열어 `QR 만들기`에서 주소를 입력하고 좌석별 QR을 다운로드합니다.

## 로컬 실행
```bash
python -m pip install -r requirements.txt
python -m streamlit run app.py
```

## 포함 기능
- 예시 좌석 20개와 좌석별 QR 접속 (`?seat=A01`)
- 이용 등록, 빈 좌석으로 변경, 반납, 내 좌석 확인
- SQLite 트랜잭션과 제약조건을 통한 중복 등록 방지
- 변경 실패 시 기존 좌석 유지
- 2시간 이용 만료 판정(조회 또는 등록 시 정리)
- 좌석별 QR PNG 생성·다운로드

## 반드시 알아둘 제한
- 인증 없는 **세션 기반 데모**입니다. 실제 학생 계정을 식별하지 않습니다. 한 사람도 여러 브라우저로 여러 좌석을 잡을 수 있습니다.
- Streamlit 세션은 영구 로그인 수단이 아닙니다. 새로고침이나 새 QR 접속으로 세션이 바뀌면 이전 좌석을 조회·반납하지 못할 수 있습니다. 즉, 새 QR을 다시 여는 실제 현장 흐름의 영구 사용자 식별은 아직 구현되지 않았습니다. 같은 실행 화면의 좌석 버튼으로 변경 기능을 시연하세요.
- SQLite 파일은 단일 서버에서 공유됩니다. 클라우드 재시작·재배포 시 유실될 수 있고 여러 서버를 사용하는 운영 환경에는 적합하지 않습니다.
- 실시간 자동 갱신, 학교 로그인, 영구 저장, 관리자, 현장 인증은 없습니다.
- QR은 공개 주소입니다. 외부에서 접속하거나 복제할 수 있습니다.
- 실제 서비스 단계에서는 Supabase 등의 외부 데이터베이스와 영구 사용자 인증을 추가하고, 이용 권한 및 개인정보 보호를 검토해야 합니다.

## 테스트
두 개의 별도 브라우저 세션에서 같은 좌석을 등록하면 한 쪽만 성공해야 합니다. 다른 세션이 사용하는 좌석으로 변경 시 기존 좌석이 유지되는지, 반납 후 다른 세션이 등록 가능한지 확인하세요.

## 설정
기본 20석, 이용 시간 7200초입니다. `app.py`의 좌석 범위와 이용 시간을 수정할 수 있습니다. 선택적으로 `KHUR_DB_PATH` 환경변수로 데이터베이스 위치를 지정할 수 있습니다. 데이터베이스 파일과 비밀키는 GitHub에 올리지 마세요.
