# KHUR · 제1·제2열람실
## 기존 앱 업데이트
1. 이 ZIP 내용물을 기존 GitHub 저장소 최상위에 올립니다. assets/khur_logo.png와 .streamlit/config.toml 폴더 구조를 유지하세요.
2. Supabase SQL Editor에서 supabase_setup.sql 전체를 실행합니다. 기존 사용자·예약은 삭제하지 않습니다. 구버전 A01~A20의 신규 등록은 중단하지만 기존 예약 반납은 가능합니다.
3. 기존 Streamlit Secrets의 SUPABASE_URL과 SUPABASE_ANON_KEY는 그대로 둡니다.
4. 앱이 갱신되지 않으면 Reboot합니다.
5. QR 출력 도구에서 제1열람실/제2열람실을 각각 선택해 QR ZIP을 생성합니다. 구버전 A01 QR은 교체해야 합니다.

좌석 ID: R1-001~R1-138, R2-001~R2-048. 예: 앱주소?seat=R2-001
제1열람실 1번과 제2열람실 1번은 독립된 좌석입니다. 계정당 두 열람실 전체에서 한 자리만 이용 가능합니다. 열람실 사이 이동 시에도 기존 좌석 자동 반납과 새 좌석 등록이 한 트랜잭션입니다.

## 배치도
제공 사진의 번호와 6석 책상 묶음을 전사했습니다. 출입구가 아래로 오도록 표시합니다. 사진의 빨간 좌석은 복제하지 않고 실제 DB 상태로 색칠합니다. 통로 폭·실제 방 비율·칸막이는 축척도가 아닙니다. 배치도는 조회용이고 QR로 등록합니다.

## 제한
시제품이며 학교 공식 서비스가 아닙니다. 정적 QR은 현장 체류 증명이 아닙니다. 로그인은 QR 재접속 시 다시 필요할 수 있습니다. 좌석 현황은 새로고침으로 갱신됩니다. QR 출력 도구는 공개 준비 도구입니다. 운영 전 학교 승인·보안·개인정보·로그인 지속성 검토가 필요합니다.

## 검증
Python 문법, 배치 번호의 중복·누락, 좌석 ID 개수, 기존 RPC 호출 유지 여부를 자동 검사했습니다. 실제 배포·Supabase SQL 실행·동시성 및 모바일 렌더링은 현장에서 검증해야 합니다.
